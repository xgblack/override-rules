# ruleset

## 目的
维护规则列表与图标资源，为覆写脚本提供可复用的分流规则来源。

## 模块概述
- **职责:** 维护 `ruleset/*.list` 与 `icons/` 资源，确保规则可用与命名一致。
- **状态:** ✅稳定
- **最后更新:** 2026-05-18

## 规范
### 需求: 规则可读与可维护
**模块:** ruleset
规则文件保持一行一条规则，避免无意义空行与重复规则。

#### 场景: 新增规则集
新增规则时需明确用途与目标分组，并在 README 中补充说明。
- 预期结果：规则语义清晰
- 预期结果：分组与图标可追溯

#### 场景: 自定义直连内网地址
`ruleset/CustomDirect.list` 包含显式内网直连规则，覆盖指定的 `10.102.0.0/16` 网段，以及常用 IPv4 私有地址、CGNAT、本地回环、链路本地地址和 IPv6 ULA/链路本地地址。
- 预期结果：内网、本机与局域网访问优先命中自定义直连规则
- 预期结果：用户指定的 `10.102.*.*` 地址段可直接访问

## API接口
无对外 API。

## 数据模型
- 规则文本列表（`ruleset/*.list`）
- 图标资源（`icons/*`）

## 依赖
- `convert.js` 读取规则与图标路径

## 变更历史
